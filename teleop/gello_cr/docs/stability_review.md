# 整体结构审查与优化（2026-10-17）

当前分支：`codex/workbench-structure-cleanup-20261017`。本轮按用户要求审查现有完整工作区，整理此前 P0–P9 改动，并在验证后推送 GitHub 新分支。

## 范围与结构

- 正式入口保持 `scripts/run_operator.sh`；历史输入和合成预览归入 examples，迁移与诊断归入 tools。
- HMI 通过命令和快照访问应用层；应用 Facade 将跟随、HOME、手部动作、轨迹、规划和采样快照交给内聚服务。
- MotionCoordinator 是运动控制权及已接受目标的来源；轨迹与规划复用 Player，采样与 Writer 分开。
- `config/workbench.json` 是唯一部署配置，保留现场标定、HOME、历史数据和已配置的主臂模式。
- 后台反馈、相机轮询、完成通知、Episode 采样及格式 Worker 具有拥有者与关闭路径；退出失败保留依赖并允许重试。
- UI 使用独立安全命令通道，记录与运动状态独立；SDK 和真实设备访问留在硬件适配层。
